# klang
It's a staticly typed rust-like language aiming to be used on the embedded envoriments with minimal dependency to runtime and operating system


# about development
This is my first time writing a programming language so expect unique or suboptimal implementations and feel free to report them.
Currently this project is under development but lexer is fully developed and ready to be used
I am currently writing the parser of the language.
After i write the parser i will write the semantic analysis and ast executer.
for now my first versions of this project will use an AST walker for execution for second version i am thinking to add an bytecode VM and for the third version i am thinking to write a compiler to compile source code into native machine code.
Thanks for checking out this project.
